### v0.2 — Бронирование ✅

**Цель:** гость записывается через UI, владелец видит встречи. Работа велась по карте решений и [спецификации](https://github.com/akozhin/ai-for-developers-project-386/issues/14) (Design First, контракт в TypeSpec).

**Ключевые результаты:**
- [x] Контракт в TypeSpec, из него OpenAPI и SDK frontend (`make generate`, проверка в CI)
- [x] БД, миграции, типы событий, слоты по рабочему расписанию, бронирования с защитой от пересечений (`EXCLUDE` в PostgreSQL)
- [x] Главный экран записи (`/`) и страница владельца (`/admin`)
- [x] Профиль владельца, `make seed` (типы 30 и 60 минут)
- [x] AI-подбор слотов на backend (`POST /api/v1/slot-suggestions`)
- [x] Сквозной сценарий проверен в браузере, тесты и CI зелёные
