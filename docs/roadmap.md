**Ключевые результаты:**
- [x] Главная страница с типами звонков (на моках) и переходом на `/book`
- [ ] БД и миграции (Alembic), модели
- [ ] API типов звонков и доступности
- [ ] Слоты и бронирование с защитой от двойной записи

**Спринты:**
