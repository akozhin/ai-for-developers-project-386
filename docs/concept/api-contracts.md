# API Contracts

> **Статус:** черновик контракта. Реализуется с sprint-03; в sprint-01 существует только `/health`. `GET /event-types` уже используется frontend на моках (sprint-02).
> **Базовый URL:** `http://localhost:8000`. **Версия:** `v1` (`/api/v1/...`), `/health` — без версии.
> **Авторизации нет** (MVP).

---

## Конвенции

- `Content-Type: application/json`, UTF-8; время — ISO 8601 в UTC.
- Ошибки — всегда JSON: `{"detail": "..."}`; ошибки валидации — 422 в формате FastAPI.
- Пустая коллекция — `200` с `items: []`.

| Код | Смысл |
|-----|-------|
| 200 | Успех |
| 201 | Ресурс создан |
| 404 | Не найден |
| 409 | Слот уже занят |
| 422 | Ошибка валидации |

## GET /health

Ответ `200`: `{"status": "ok"}`

## GET /api/v1/event-types

Ответ `200`:

```json
{ "items": [ { "id": "uuid", "title": "Консультация", "duration_minutes": 30 } ] }
```

Пустой список — `{ "items": [] }`.

## GET /api/v1/event-types/{id}/slots

Ответ `200`:

```json
{ "items": [ { "starts_at": "2026-10-08T08:00:00Z", "ends_at": "2026-10-08T08:30:00Z" } ] }
```

## POST /api/v1/bookings

Запрос:

```json
{ "event_type_id": "uuid", "starts_at": "2026-10-08T08:00:00Z", "guest_name": "Анна", "guest_email": "anna@example.com" }
```

| Поле | Тип | Обязательное |
|------|-----|:---:|
| `event_type_id` | uuid | ✅ |
| `starts_at` | datetime (UTC), должен совпадать со слотом | ✅ |
| `guest_name` | string | ✅ |
| `guest_email` | email | ✅ |

Ответы: `201` — созданная запись; `404` — тип звонка не найден; `409` — слот занят или вне доступного времени; `422` — невалидные данные.
