# Запись на звонок

Упрощённый сервис бронирования времени: владелец публикует типы событий, гость выбирает свободный слот и бронирует его без регистрации.

## Language

**Владелец**:
Единственный хозяин календаря: создаёт типы событий, смотрит предстоящие встречи. Заранее заданный профиль, авторизации нет.
_Avoid_: Админ, пользователь, хост

**Гость**:
Анонимный посетитель, который бронирует слот без регистрации и входа.
_Avoid_: Клиент, пользователь, посетитель

**Тип события**:
Вид звонка, который предлагает владелец: название, описание и длительность в минутах («Консультация, 30 минут»). В коде — `EventType`.
_Avoid_: Тип звонка, услуга, событие

**Слот**:
Свободный интервал времени под конкретный тип события, который гость может забронировать. Начинается на границе сетки слотов; длительность задаёт тип события.
_Avoid_: Окно, время приёма

**Сетка слотов**:
Шаг (30 минут), на границах которого могут начинаться слоты любых типов событий.
_Avoid_: Расписание

**Рабочее расписание**:
Единое для всех типов событий время, в которое владелец принимает гостей. Задаётся конфигурацией, не через API.
_Avoid_: Доступность, правила доступности

**Окно записи**:
Период, в котором гость может бронировать: 14 дней, начиная с текущей даты по часовому поясу владельца. Слоты ближе, чем запас до записи (по умолчанию 2 часа) от «сейчас», недоступны.
_Avoid_: Горизонт

**Запас до записи**:
Минимальное время между «сейчас» и началом слота, при котором слот ещё можно забронировать.
_Avoid_: Лаг, буфер

**Бронирование**:
Подтверждённая бронь гостя на слот: имя, email, необязательный комментарий, время. В коде — `Booking`. Два бронирования любых типов не пересекаются по времени. Действие гостя называем «забронировать» или «записаться».
_Avoid_: Запись (как существительное), заявка

**Встреча**:
Бронирование в списке предстоящих встреч владельца; в списке вместе показаны встречи всех типов событий.
_Avoid_: Звонок
